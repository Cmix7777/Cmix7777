# Айзат

Учусь на разработчика и иду в тестирование: хочу работать тестировщиком ПО. Свои проекты я не только пишу, но и проверяю: у главного из них есть автотесты, нагрузочные замеры и проверка самих тестов, и всё это запускается на чистой машине GitHub при каждом изменении.

## Главное

[BookClub](https://github.com/Cmix7777/BookClub) — сайт книжных клубов с анонимным голосованием на ASP.NET Core и PostgreSQL. К нему написано 221 автоматическая проверка (запросы к API и сценарии в настоящем браузере), нагрузочные сценарии на k6 и мутационное тестирование Stryker.NET: тесты замечают 94,8% внесённых в код поломок. В описании проекта объяснено, как всё устроено и как запустить.

[Каждыйдневник](https://github.com/Cmix7777/kazhdyidnevnik) — личное Android-приложение на Kotlin и Jetpack Compose: расписание, план учёбы, дела, бюджет и погода. Дела можно передавать второму телефону через облако в зашифрованном виде, а экраны проверяются автотестами на эмуляторе в GitHub Actions.

## Другие примеры

[ToTDoo](https://github.com/Cmix7777/ToTDoo) — список задач на ASP.NET Core MVC, Entity Framework Core и SQLite.

[AptekaPlus](https://github.com/Cmix7777/AptekaPlus) — интернет-аптека на Laravel 11 с каталогом, корзиной и админ-панелью.

[Tele-Bum](https://github.com/Cmix7777/Tele-Bum) — простой редактор статей на Nuxt 3 и Editor.js: пишешь текст блоками и получаешь ссылку на страницу статьи.

## С чем работаю

Разработка: C#, ASP.NET Core, Entity Framework Core, PostgreSQL, Kotlin, Jetpack Compose, PHP и Laravel, Vue и Nuxt.

Тестирование: xUnit для проверок API, Playwright для браузера, k6 для нагрузки, Stryker.NET для проверки самих тестов, тесты экранов Android на эмуляторе, GitHub Actions для автоматического запуска.
